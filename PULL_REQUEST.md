# New Features and Improvements (yippie!1!111!)

### 1. New Features frfr
- **Separated the Mods from the means of Updating**: New dedicated Updating procedure which is less weird than the one before
- **View Workshop button**: to jump straight to the mod's Steam Workshop page in the Steam client
- **Clear Steam ID button**: to upload it as a fresh steam workshop upload
- **Smarter disclaimer updater**: uses regex to cleanly overwrite the existing disclaimer between dividers on update instead of duplicating it or breaking if edited

### 4. Misc. Stuff
- **Full localization** for all new buttons, titles, and dialogs in English, Simplified Chinese, and Traditional Chinese
- **Missing icon safeguard**: falls back to the default NML icon instead of throwing an error if `icon.png` is missing
- **Thread-safe compilation caching** during parallel mod builds
